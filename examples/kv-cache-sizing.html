KV cache size explorer

The cache holds one key and one value vector per layer, per token, per KV head.

bytes = 2 × n_layers × n_kv_heads × head_dim × seq_len × batch × bytes_per_elem

Assumptions

  • The model stores K and V separately (the factor 2).
  • No cache compression, paging overhead, or quantization beyond the dtype you pick.
  • Defaults match Llama-3-8B: 32 layers, 8 KV heads (GQA), head_dim 128.
